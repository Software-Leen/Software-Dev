- Repository Permissions

* Admin: Full access to repository management and settings.
* Write: Permission to contribute and modify repository content.
* Read: Permission to view and clone repository content.

- Branch Protection

The repository includes a ruleset configured to protect the main branch.

The configured rules include:

* Pull request reviews before merging.
* Protection against force pushes.
* Restrictions on branch deletion.


- Collaboration Workflow

1. Team members access the repository according to their assigned roles.
2. Members with Write access can create branches and submit changes.
3. Changes are proposed through Pull Requests.
4. Pull Requests are reviewed before merging into main.
